# Codesud Scanner

Aplicación de Codesud para escanear documentos desde mediweb en Windows 10 y 11.

## Descarga

**[Descargar Codesud Scanner para Windows](https://github.com/codesud-chile/codesud-scanner/releases/latest/download/CodesudScanner-setup.exe)**

El enlace entrega siempre la última versión.

## Instalación

1. Abre el archivo descargado, `CodesudScanner-setup.exe`.
2. Si Windows muestra «Windows protegió su PC», pulsa **Más información** y luego **Ejecutar de todas formas**.
3. Sigue el asistente. No necesita permisos de administrador.
4. En mediweb, pulsa el botón de escanear. La primera vez el navegador pregunta si puede abrir Codesud Scanner: acepta, y elige tu escáner, el color y la calidad.

El escáner debe estar conectado, encendido y con el driver del fabricante instalado.
